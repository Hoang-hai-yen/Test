# Open-Gallery / Open-Set Re-Identification: Suppressing False Matches When the Target Is Absent

## What score normalization / re-ranking techniques does open-set person ReID use to decide "is this a match at all" (vs. forced closed-set top-1)?

### Takeaway
Open-set person ReID reframes matching as **verification** (score vs. threshold) rather than pure retrieval, using Detection-and-Identification Rate (DIR) vs. False Accept Rate (FAR) curves; standard closed-set tricks like k-reciprocal re-ranking and naive query expansion are not guaranteed to help and can even hurt open-set/absent-target decisions, so newer work uses explicit **score calibration** (isotonic calibration, cohort/AS-norm) and **loss functions that directly separate genuine from imposter score distributions** rather than relying on ranking quality alone.

### Cited Findings
- The original open-set person re-ID formulation (Zheng et al.) treats it as person verification plus identification: a similarity/distance must exceed a threshold `h` for a probe to be "detected" as present in the gallery at all; sweeping this threshold traces out True Target Rate (TTR) vs. False Target Rate (FTR), i.e., a DIR vs. FAR curve, rather than a single closed-set rank-1 accuracy number — [Open-set Person Re-identification](https://arxiv.org/abs/1408.0872); summarized also in [Open-world Re-ID: Methods & Challenges](https://www.emergentmind.com/topics/open-world-re-id)
- Given a target FAR, the corresponding decision threshold is read off the DIR-vs-FAR (ROC-like) curve, and a CMC-style DIR-vs-rank curve is then plotted *at that fixed FAR* — this is the standard open-set evaluation protocol, distinct from closed-set CMC/mAP — [Open-world Re-ID: Methods & Challenges](https://www.emergentmind.com/topics/open-world-re-id)
- The "Re-identification = Retrieval + Verification" paper argues standard re-ID metrics (rank-1, mAP) only score ranking quality and cannot tell a user "which images are the true target," and proposes the **Genuine Open-set re-ID Metric (GOM)**, which combines retrieval and verification into one metric and decomposes into interpretable sub-metrics so that a decision threshold can be tuned to different false-accept/false-reject requirements; evaluated on Market-1501, DukeMTMC-reID, and the vehicle dataset VeRi776 — [Re-identification = Retrieval + Verification (arXiv 2011.11506)](https://arxiv.org/abs/2011.11506); [GOM overview](https://www.emergentmind.com/topics/genuine-open-set-re-id-metric-gom); [GOM code](https://github.com/YuanXinCherry/Person-reID-Evaluation)
- There is a dedicated paper directly asking **"Is Re-ranking Useful for Open-set Person Re-identification?"**, indicating the ReID community itself treats it as an open, non-obvious question whether k-reciprocal-style re-ranking (designed to boost closed-set rank-1/mAP) transfers to the open-set absent-target case — [Is Re-ranking Useful for Open-set Person Re-identification?](https://www.researchgate.net/publication/330632363_Is_Re-ranking_Useful_for_Open-set_Person_Re-identification) (full text was not retrievable — see Gaps)
- Classic k-reciprocal re-ranking (Zhong et al., CVPR 2017) re-ranks by fusing the original distance with a Jaccard distance computed over k-reciprocal nearest-neighbor sets, on the hypothesis that true matches share reciprocal neighbors; it was evaluated partly on MARS, which already contains 3,248 **distractor sequences** (false detections/tracking failures) as a proxy for open-set noise — [Re-ranking Person Re-identification with k-reciprocal Encoding (CVPR 2017)](https://openaccess.thecvf.com/content_cvpr_2017/papers/Zhong_Re-Ranking_Person_Re-Identification_CVPR_2017_paper.pdf)
- Query expansion (QE) methods average the query feature with its top-k retrieved neighbors' features before re-querying (Average QE); **Bayesian Query Expansion** instead trains a model on inter-image distances to estimate the *probability* that each gallery image is a true match, and only pools the features of images likely to be true matches into the expanded query — a probabilistic/calibrated variant more suited to filtering out false candidates than naive AQE — [Bayesian Query Expansion for Multi-Camera Person Re-identification](https://vana77.github.io/images/prl_reid.pdf)
- For open-set animal re-ID, the WildFusion pipeline applies **Isotonic Calibration** (not raw cosine/Euclidean distance) to each of three similarity branches (a global descriptor branch MiewID, and two local keypoint-matching branches ALIKED+LightGlue and DISK+LightGlue) so that fused scores are comparable and thresholdable; critically, the calibration mapping is fit *after* segmentation but *before* species-specific preprocessing to keep it generalizable — [Calibrated Similarity and Graph Clustering for Open-Set Animal Re-Identification (arXiv 2608.02469)](https://arxiv.org/html/2608.02469)
- That same paper adds two further score-level safeguards before accepting a query as matching a known identity: (1) a query image counts as a confident match only if its best similarity `b_i ≥ τ_attach` **and** its margin over the second-best identity `m_i ≥ τ_margin` (a margin check, not just an absolute threshold); (2) identity-level scores are computed as the **average of the top-r similarities** between the query and each identity's reference images (not just the single best match), reducing sensitivity to one lucky/unlucky comparison — [Calibrated Similarity and Graph Clustering for Open-Set Animal Re-Identification](https://arxiv.org/html/2608.02469)
- The cattle-muzzle open-set benchmark (2026) explicitly ports face-recognition / speaker-verification score-normalization techniques into an animal re-ID open-set protocol, testing **AS-norm** (adaptive symmetric score normalization, from speaker verification), **OpenMax**, and angular-margin embeddings alongside plain cosine similarity with **threshold-based rejection**; empirically, "plain cosine is the best or numerically closest at every operating point," meaning fancier score-normalization did not clearly beat simple calibrated cosine similarity with a well-chosen threshold — [Open-Set Cattle Muzzle Identification: A Leakage-Controlled Benchmark and Evaluation Protocol (arXiv 2608.28663)](https://arxiv.org/html/2608.28663)
- "Open-Set Biometrics: Beyond Good Closed-Set Models" (ECCV 2024) argues that standard closed-set losses (e.g., triplet/softmax variants) treat genuine and imposter score pairs symmetrically and ignore the *relative magnitude* of imposter (false-match) scores, which is precisely what matters for open-set rejection; it proposes an **Identification-Detection Loss** and a **Relative Threshold Minimization** loss that explicitly reduce the maximum negative (imposter) score per probe during training, and simulates open-set evaluation with unknown/known minibatches during training rather than only at test time — [Open-Set Biometrics: Beyond Good Closed-Set Models (ECCV 2024)](https://mlanthology.org/eccv/2024/su2024eccv-openset/)
- The MICRO-TRACK industrial open-set person ReID system uses a simple two-threshold cascade rather than re-ranking: a detection-confidence threshold `th_score` gates which detections even attempt re-ID (filtering low-quality/occluded crops), and a separate embedding-distance threshold `th_emb` (Euclidean distance to class centroids) decides match vs. "novel identity"; on their Facility-ReID dataset the operating point that balanced tracker-reliance vs. re-ID frequency was `th_score ≈ 0.91–0.92`, yielding Precision 0.908 / Accuracy 0.790 / True Target Rate 0.909 (Market-1501-as-open-set gave Precision 0.888 / Accuracy 0.720 / TTR 0.740) — [Multi-Camera Industrial Open-Set Person Re-Identification and Tracking (arXiv 2409.03879)](https://arxiv.org/html/2409.03879v1)

### Inferences
- The field has moved away from "closed-set metric + manually chosen threshold" toward treating threshold calibration as a first-class, learned/validated step (isotonic calibration, cohort normalization, loss functions that shape the imposter-score distribution). For a tiny reference-gallery deployment, plain **calibrated cosine/Euclidean similarity with a margin-over-second-best check**, averaged/aggregated over multiple reference images per identity (top-r pooling), appears to be a robust, low-complexity pattern repeatedly reinvented across person, animal, and livestock ReID papers — more load-bearing than exotic re-ranking.
- Re-ranking methods built for closed-set retrieval quality (k-reciprocal, AQE) are not validated as safe for the open-set "reject everything" case and may propagate false positives by pulling in neighbors of a false match; a margin/calibration-based accept rule is the more defensible design choice when the target may be genuinely absent.

## How does open-set ReID handle the class imbalance of "target absent" being the common case, and what FAR-focused benchmarks/techniques exist?

### Takeaway
Open-set ReID benchmarks explicitly split identities into **known (gallery) vs. unknown/distractor probes** and report performance at fixed, often very low, FAR operating points (10⁻¹, 10⁻², 10⁻³) rather than a single closed-set accuracy number; state-of-the-art results show this remains hard — reported DIR at low FAR is often in the single digits to modest double digits for older methods, and even recent well-calibrated systems show real "oracle-threshold vs. deployable-threshold" gaps.

### Cited Findings
- The open-set evaluation protocol explicitly reports **Detection and Identification Rate (DIR)** at fixed **False Accept Rate (FAR)** operating points, computed as the fraction of truly-absent probes that get wrongly matched below the distance threshold — this directly targets the "most probes are target-absent" imbalance instead of averaging over a gallery assumed to always contain the query — [Open-world Re-ID: Methods & Challenges](https://www.emergentmind.com/topics/open-world-re-id)
- Reported difficulty: on an open-set benchmark, the best method achieved only **3.99% DIR at rank-1 under FAR = 10%**, illustrating how hard low-false-accept operation is even at a relatively generous 10% FAR budget — [Open-world Re-ID: Methods & Challenges](https://www.emergentmind.com/topics/open-world-re-id) (specific paper/year not resolved further — see Gaps)
- The new **Open-Set Cattle Muzzle Identification benchmark** (2026) is explicitly built around a "leakage-controlled" open-set protocol to fix a measurement artifact: an initial naive open-set split produced a spuriously high FAR=10⁻² detection rate of **23.8% ± 20.9%** purely from identity leakage between train/gallery/unknown splits. Their fix uses fully identity-disjoint splits: ~50% known (124 IDs) / ~20% validation-unknown (50 IDs) / ~30% test-unknown (75 IDs), 5 repeated partitions with per-fold retraining, and threshold calibration using *only* the validation-unknown split (never training data) — a template applicable to any tiny-gallery open-set design that wants an honest FAR estimate — [Open-Set Cattle Muzzle Identification (arXiv 2608.28663)](https://arxiv.org/html/2608.28663)
- That benchmark reports oracle (test-set-optimal, "cheating") thresholds achieving DIR@FAR=10⁻² of 96.4% (hybrid model) and 98.1% (MegaDescriptor-L), but under **realistic, deployable calibration** (threshold fixed from validation data only) the hybrid model's FAR rose to 1.03% at a 1%-target operating point, and MegaDescriptor-L rose to 2.44% FAR — i.e., roughly 2x the intended false-accept budget just from the oracle→deployable threshold gap. It uses OSCR-AUC, Open-Set AUROC, and Equal Error Rate (EER) as the additional summary metrics, plus 2000-resample bootstrap 95% CIs clustered by identity for statistical confidence — [Open-Set Cattle Muzzle Identification (arXiv 2608.28663)](https://arxiv.org/html/2608.28663)
- "Open-Set Biometrics: Beyond Good Closed-Set Models" (ECCV 2024) diagnoses the imbalance problem at the *training* level: because standard losses treat all imposter pairs symmetrically, models are not explicitly pushed to keep the *maximum* imposter score low (the score that actually determines false accepts), so they propose training-time losses (Identification-Detection Loss, Relative Threshold Minimization) that directly target this, validated across face recognition, gait recognition, and person re-ID — [Open-Set Biometrics (ECCV 2024)](https://mlanthology.org/eccv/2024/su2024eccv-openset/)
- DeepChange (ICCV 2023) is a large, realistic long-term person ReID benchmark (178K boxes, 1.1K identities, 12 months of collection) — relevant to streaming/long-term deployment realism, but it is framed around long-term clothes-change matching rather than an explicit FAR-focused open-set protocol — [DeepChange (GitHub/ICCV 2023)](https://github.com/PengBoXiangShang/deepchange)
- A dedicated arXiv paper on "Operational Open-Set Recognition and PostMax Refinement" (ECCV 2024) proposes **Operational Open-Set Accuracy (OOSA)**, which requires predicting an operationally-relevant threshold from a validation set containing both known and a *surrogate* set of unknowns, then freezing and applying that threshold at test time — directly analogous to needing a distractor/unknown validation pool to pick a safe operating threshold before deployment — [Operational Open-Set Recognition and PostMax Refinement (ECCV 2024 PDF)](https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/01043.pdf)

### Inferences
- The recurring theme across 2024–2026 open-set benchmarks (cattle muzzle, biometrics ECCV 2024, Operational OSR) is that a threshold picked "in sample" (oracle/training-tuned) systematically underestimates real-world FAR; a held-out unknown/distractor validation pool, disjoint by identity from both training and test, is treated as mandatory rather than optional for a trustworthy open-set operating point. For a streaming deployment where most frames are target-absent, this implies the accept threshold must be validated against a large pool of genuinely-different-identity detections, not just tuned against the few known positives.
- No open-set person/vehicle ReID benchmark surveyed reports single-digit FAR operation with high DIR as a solved problem — even strong recent systems concede meaningful gaps between oracle and deployable thresholds, reinforcing that a production system needs conservative (high-precision-biased) thresholds and should expect a non-trivial false-accept floor.

### Gaps
- Could not pin down the exact paper/year behind the "3.99% DIR at rank-1 under FAR=10%" statistic beyond the secondary summary page; the primary source was not directly located in this pass.
- No explicit person-ReID "distractor set" benchmark analogous to MegaFace (face recognition) was found in this search pass — MARS's 3,248 distractor sequences is the closest analog identified, but no dedicated large-scale person-ReID distractor benchmark (with millions of hard negatives) was surfaced. This may exist but wasn't found within the tool-call budget.

## What role does gallery updating (online gallery expansion) play, and what safeguards exist against gallery poisoning?

### Takeaway
Multiple 2023–2024 open-world ReID papers implement online/self-adaptive gallery expansion as a **confidence + diversity + entropy gated pipeline**, routing uncertain detections into an "unknown" holding pool instead of the gallery, explicitly to prevent a false match from being added and poisoning future matches — this is a close functional analog to the "recently accepted detections as extra anchors" design in question.

### Cited Findings
- The **Self-Adaptive Gallery Construction** method (Sensors 2023) decides whether to add a new detection to an existing identity class using a confidence-margin test on classifier probabilities: `max_i p_i(x_q) / max_{j≠i} p_j(x_q) ≥ τ`, with the expansion threshold empirically set to **τ = 2**; samples that fail this margin test are *not* discarded but routed to an "unknown data manager" for later re-evaluation rather than immediately added or immediately dropped — [A Self-Adaptive Gallery Construction Method for Open-World Person Re-Identification (Sensors 2023 / PMC10007633)](https://pmc.ncbi.nlm.nih.gov/articles/PMC10007633/)
- That same method applies three explicit anti-poisoning safeguards before a sample can enter the gallery: (1) a **quality filter** requiring the appearance descriptor represent at least half of a visible person (skeleton-visibility gate) before any matching is attempted; (2) a **diversity-based admission rule** — a new sample is only added to a class if it *increases* that class's intra-class diversity beyond its current level (Eq. 7), preventing near-duplicate/uninformative adds; (3) an **entropy-based pruning step** using Shannon entropy over inter-class ambiguity to remove redundant or confusing samples already in the gallery — an active "garbage collection" against drift, not just gated intake — [Self-Adaptive Gallery Construction (PMC10007633)](https://pmc.ncbi.nlm.nih.gov/articles/PMC10007633/)
- Reported results of this approach: Gallery Structure F1 of 62.67% (MARS) / 72.62% (DukeMTMC-VideoReID), Class Precision 76.9% (MARS) / 80.1% (DukeMTMC-VideoReID), and person-identification recall of 89.43% (MARS) / 80.06% (DukeMTMC-VideoReID) — achieved while keeping the gallery to only **8.1% (MARS) / 18.4% (DukeMTMC-VideoReID)** of the size of a fully-labeled gallery, i.e., aggressive pruning/selectivity rather than unbounded accumulation — [Self-Adaptive Gallery Construction (PMC10007633)](https://pmc.ncbi.nlm.nih.gov/articles/PMC10007633/)
- The MICRO-TRACK industrial system's **Open-Set Gallery (OSG)** keeps only a bounded, fixed-size **circular buffer of K embeddings per identity** (not an ever-growing set), matches via Euclidean distance to class centroids, and only creates a *new* identity when the minimum distance to all existing centroids exceeds embedding threshold `th_emb` — bounding both memory growth and the blast radius of any one bad embedding (it ages out of the circular buffer) — [Multi-Camera Industrial Open-Set Person Re-Identification and Tracking (arXiv 2409.03879)](https://arxiv.org/html/2409.03879v1)
- General framing from the wider search: static, preset galleries are recognized as a poor fit for open-world/streaming deployments (new people, detection errors, "junk" data accumulate over time), motivating dynamic/online gallery learning that **automatically estimates the number of frequently-appearing identities and updates their appearance models online** — [Online learning of dynamic multi-view gallery for person Re-identification](https://link.springer.com/article/10.1007/s11042-015-3015-5); reinforced in the open-world survey framing — [Self-Adaptive Gallery Construction (PMC10007633)](https://pmc.ncbi.nlm.nih.gov/articles/PMC10007633/)
- In a related but distinct context (material/appearance aging over long deployments), one paper's finding was that **"a continuously updated gallery is what preserves identity under material aging, not a better feature extractor alone"** — i.e., gallery updating is treated as doing real, non-substitutable work relative to model quality — [Enhancing Long-Term Re-Identification Robustness Using Synthetic Data (arXiv 2504.18286)](https://arxiv.org/pdf/2504.18286) (found via secondary summary; primary quote not independently re-verified against full PDF text — see Gaps)
- In the open-set animal re-ID (WildFusion) pipeline, gallery/identity attachment uses **cluster-level voting** as an additional poisoning safeguard beyond per-image thresholds: individual confidently-matched images cast weighted votes for an identity, and a whole cluster (produced by Chinese-Whispers graph clustering of the probe pool) is only assigned to a known identity if at least one of its members received such votes and that identity has the highest accumulated vote — meaning a single ambiguous/false match cannot unilaterally attach a cluster to the wrong identity; it needs corroboration — [Calibrated Similarity and Graph Clustering for Open-Set Animal Re-Identification (arXiv 2608.02469)](https://arxiv.org/html/2608.02469)
- The same paper's identity-level score is computed as the **average of the top-r similarities** (r=1–5, species-dependent) between a query and *each* identity's stored references, rather than best-of-all — meaning as the gallery/reference set for an identity grows, a single mistakenly-added false reference has bounded influence (diluted by averaging) rather than being able to single-handedly swing future matches — [Calibrated Similarity and Graph Clustering (arXiv 2608.02469)](https://arxiv.org/html/2608.02469)

### Inferences
- Every online-gallery-expansion method found uses the same core pattern applicable to a "3-reference-photo + recently-accepted-detections" design: **(a) gate additions with both an absolute confidence/similarity threshold and a margin-over-runner-up check, (b) require some form of corroboration or diversity gain rather than accepting any single high-scoring detection outright, (c) aggregate/average across multiple stored references per identity so no single bad addition dominates the decision, and (d) bound the reference pool size (circular buffer, pruning) so poisoned or stale entries eventually age out.** This is a much stronger design than "add anything above threshold X" and is exactly the kind of safeguard a false-match-poisoning-resistant design should borrow.
- None of the papers found describe an explicit *rollback* mechanism (detecting and removing a poisoned entry after the fact, once contradicting evidence appears) — the safeguards found are all "prevent bad entry" (gating) rather than "detect and cure a bad entry already admitted," which is a real gap for a long-running streaming system.

### Gaps
- No paper explicitly used the term "gallery poisoning"; this is an inferred framing from safeguard designs against false-match propagation via online gallery expansion, not a term-of-art the literature has standardized on. Treat the safeguard mechanisms above as the closest available evidence rather than a body of work self-identified as being about "poisoning."
- No paper was found that explicitly evaluates *cascading* false-match propagation (i.e., measuring how many downstream false accepts are caused by one earlier false gallery addition) as its own metric — this would be the most directly relevant ablation for a design worried about compounding errors, but it does not appear to exist as a standard evaluation in the surveyed literature.
- The "Enhancing Long-Term Re-ID Robustness Using Synthetic Data" quote about continuous gallery updates was obtained via a WebSearch snippet/secondary source, not verified against the full primary PDF text — flagged for direct verification if this claim needs to be load-bearing.

## What do vehicle ReID / wildlife re-ID do differently from person ReID, given fewer reference images and streaming deployment?

### Takeaway
Wildlife/animal re-ID work is arguably the closest existing analog to a 3-reference-photo open-gallery streaming setting: it leans heavily on **metric-learning embeddings that need only one or a few reference images**, explicit **open-set/incremental-enrollment protocols** (testing with n=1,3,5,8 reference images), **multi-branch local+global matching fused via calibration**, and **graph clustering to both verify known identities and discover new ones simultaneously** — capabilities generic person-ReID pipelines rarely need to combine.

### Cited Findings
- General framing: "in most cases the individual being probed would not appear in the gallery set" is treated as the *default* assumption in animal re-ID (not an edge case), and **metric-learning methods are specifically favored because they are similarity-based and require only a single example of an individual**, unlike data-hungry classification CNNs needing tens-to-hundreds of images per class — [Deep Learning Methods for Multi-Species Animal Re-identification and Tracking – a Survey](https://www.sciencedirect.com/science/article/abs/pii/S1574013720303890) (via search synthesis)
- The cattle-muzzle open-set benchmark explicitly tests **incremental enrollment with as few as 1 reference image per identity** (n ∈ {1,3,5,8}), finding single-image enrollment already achieves 91.08% Rank-1 accuracy with a hybrid model — direct evidence that few-shot (even one-shot) enrollment is a first-class, benchmarked capability in animal re-ID, unlike most person-ReID benchmarks which assume galleries with many images per identity — [Open-Set Cattle Muzzle Identification (arXiv 2608.28663)](https://arxiv.org/html/2608.28663); dataset averaged 18.4 images/animal (median 16, range 4–70) for the *base* (non-incremental) protocol
- The same benchmark explicitly imports **face-recognition and speaker-verification-style score normalization** (AS-norm, OpenMax, angular-margin embeddings) into the animal re-ID setting, i.e., wildlife/livestock re-ID researchers are self-consciously borrowing open-set verification machinery from biometrics rather than from person-ReID retrieval literature — [Open-Set Cattle Muzzle Identification (arXiv 2608.28663)](https://arxiv.org/html/2608.28663)
- The WildFusion open-set animal re-ID pipeline fuses **one global descriptor branch (MiewID) with two local keypoint-matching branches (ALIKED+LightGlue, DISK+LightGlue)**, i.e., combines learned global embeddings with classical local feature matching/geometric verification — a hybrid not typically used in mainstream deep person-ReID, which relies almost exclusively on global (or part-based) CNN/transformer embeddings — [Calibrated Similarity and Graph Clustering for Open-Set Animal Re-Identification (arXiv 2608.02469)](https://arxiv.org/html/2608.02469)
- That pipeline also explicitly performs **simultaneous verification-and-discovery**: known-identity attachment via per-image threshold+margin and cluster voting (described above), *and* **Chinese-Whispers graph clustering** to group unmatched probe images into new candidate identity clusters — the paper frames this as a genuine departure from "purely closed-set" person ReID, since the task requires "both match images of known individuals and discover previously unseen individuals by grouping their observations correctly" — [Calibrated Similarity and Graph Clustering (arXiv 2608.02469)](https://arxiv.org/html/2608.02469)
- Metric-learning/Siamese-network approaches are repeatedly cited as favored for tiger re-identification specifically because of limited images per identity — consistent with the ATRW benchmark (Amur Tiger Re-identification in the Wild: 8,000+ video clips, 92 tigers) being built around unconstrained, sparse-per-individual captures rather than dense per-identity galleries — [ATRW: A Benchmark for Amur Tiger Re-identification in the Wild](https://dl.acm.org/doi/abs/10.1145/3394171.3413569); tiger conservation deep-learning summary — [Preserving the Apex: Enhancing Tiger Conservation with Deep Learning](https://medium.com/@prasanNH/preserving-the-apex-enhancing-tiger-conservation-with-deep-learning-5065d961b620)
- ElephantBook is described as a **semi-automated, human-in-the-loop** elephant re-identification system — i.e., rather than a fully automatic accept/reject threshold, it is explicitly designed to route uncertain matches to a human for confirmation, an architecture pattern (auto-accept high confidence / auto-reject low confidence / human-review the middle band) that is a plausible safeguard for a tiny-gallery streaming design, though the specific thresholds used were not extractable from the source in this pass — [ElephantBook: A Semi-Automated Human-in-the-Loop System for Elephant Re-Identification (arXiv 2106.15083)](https://arxiv.org/pdf/2106.15083) (full text not machine-readable in this pass — see Gaps)
- A general-purpose few-shot animal re-ID framework (Wahltinez et al., Methods in Ecology and Evolution 2024) was evaluated across multiple species (tigers, cattle noses, chimpanzee faces, zebras, giraffes, ringed seals) using few-shot learning, underscoring that **cross-species, small-reference-set re-ID is an established sub-field with its own open-source tooling** (also see the WACV 2024 `wildlifedatasets` toolkit) — [An open-source general purpose machine learning framework for individual animal re-identification using few-shot learning](https://besjournals.onlinelibrary.wiley.com/doi/full/10.1111/2041-210X.14278) (full text blocked by 403 in this pass — see Gaps); toolkit reference via search synthesis, "Wildlifedatasets... published at WACV 2024"
- WildlifeReID-10k is noted as a large-scale (10k individual animals) wildlife re-ID dataset aggregation, relevant as a benchmark resource but its open-set-specific protocol details were not extracted in this pass — [WildlifeReID-10k (arXiv 2406.09211)](https://arxiv.org/pdf/2406.09211) (not fetched in full — see Gaps)
- No specific vehicle-ReID paper with an explicit "open-set unknown-identity rejection" framing and concrete threshold numbers was found; search results mostly returned general open-set re-ID framing statements ("the system must... determine when a probe does not correspond to any known individual") without a named, citable vehicle-specific paper — the GOM paper (above) is the only source found that evaluates a vehicle dataset (VeRi776) under an explicit open-set metric — [Re-identification = Retrieval + Verification (arXiv 2011.11506)](https://arxiv.org/abs/2011.11506)

### Inferences
- Wildlife/livestock re-ID is a better direct analog than person ReID for a 3-reference-photo open-gallery streaming design: it has normalized around few-shot/one-shot enrollment, explicit calibrated-score + margin-based accept rules, hybrid global+local matching for extra verification signal when reference counts are low, and (in at least one case, ElephantBook) a human-in-the-loop tier for uncertain cases rather than forcing a fully-automatic binary decision.
- Vehicle ReID specifically appears comparatively under-served by explicit open-set/FAR-focused framing in the literature surfaced here — most vehicle-ReID work found is closed-set retrieval-accuracy focused, with GOM's VeRi776 evaluation being the main open-set exception located. This should not be read as vehicle-ReID lacking open-set concerns, but as this being a smaller, less mature sub-literature than person or wildlife open-set ReID as of this search.

### Gaps
- ElephantBook's and the Wahltinez et al. few-shot framework's full-text technical details (exact thresholds, precision/recall numbers, reference-image counts) could not be extracted — PDF/403 fetch failures in this pass. These are flagged as promising sources worth a direct manual read.
- Could not find a vehicle-ReID-specific paper with concrete open-set FAR/threshold operating points beyond the general framing snippets and GOM's VeRi776 use — this may be a genuine literature gap or simply not surfaced within the tool budget.
- WildlifeReID-10k's specific open-set evaluation protocol (if any) was not extracted from the primary source in this pass.

## Are there 2023–2025 single/few-shot object re-identification papers (non-person) with concrete precision-recall operating points and threshold rationale for open-set streaming deployment?

### Takeaway
A few-shot/single-shot object re-ID benchmark (ISAR, WACV 2024) and several very recent (2025–2026) animal/livestock open-set re-ID papers exist and are directly relevant, but most of the concrete precision/recall/threshold numbers this report was able to fully extract come from the animal/livestock side (cattle muzzle, WildFusion) rather than from generic non-person object categories — suggesting the "few-shot object re-ID with an explicit open-set operating point" niche is still populated mainly by wildlife/biometrics-adjacent work rather than general object re-ID.

### Cited Findings
- **ISAR** (arXiv 2311.02734, WACV 2024) is presented as "a benchmark and baseline method for single- and few-shot object Instance Segmentation And Re-identification," explicitly aiming to unify few-shot semantic segmentation, video object segmentation (VOS), and re-identification (re-ID) under one benchmark, using a semi-synthetic dataset of video sequences with ground-truth annotations and a standardized evaluation pipeline — [ISAR: A Benchmark for Single- and Few-Shot Object Instance Segmentation and Re-Identification (arXiv 2311.02734)](https://arxiv.org/abs/2311.02734)
- A zero-shot object re-identification paper targeting egocentric kitchen videos via multi-stage SAM3 feature fusion was located (arXiv 2605.26383, Klepachevskyi, Wong, Rambhatla, Chen) — title and venue confirm this is a directly on-topic, very recent (2026) non-person object re-ID paper for a streaming/video setting, but its PDF content could not be parsed by the fetch tool in this pass, so specific threshold/precision-recall numbers could not be extracted — [Zero-Shot Object Re-Identification in Egocentric Kitchen Videos via Multi-Stage SAM3 Feature Fusion (arXiv 2605.26383)](https://arxiv.org/pdf/2605.26383)
- The closest fully-extracted concrete precision/recall + explicit threshold-rationale example, though for animals rather than generic objects, is the cattle-muzzle benchmark: it reports Rank-1 91.08% for single-image (one-shot) enrollment, and shows the deployable-threshold FAR (1.03%–2.44%) vs. oracle-threshold FAR (implied ~1%) gap explicitly, with the threshold chosen via a held-out validation-unknown split rather than by inspection of the test set — a concrete, reproducible "how did they pick the threshold" answer — [Open-Set Cattle Muzzle Identification (arXiv 2608.28663)](https://arxiv.org/html/2608.28663)
- Similarly, the WildFusion open-set animal re-ID paper (2608.02469) reports concrete operating results (public ARI 0.72124, private ARI 0.70393) and explicit per-branch thresholds (`τ_attach`, `τ_margin`, `τ_CW` for clustering, `k_NN`, `k_core`), i.e., a fully specified, reproducible threshold rationale for an open-set streaming-style deployment (a Kaggle-style competition pipeline design), even though it targets lynx/salamander/sea-turtle identification rather than generic manufactured objects — [Calibrated Similarity and Graph Clustering for Open-Set Animal Re-Identification (arXiv 2608.02469)](https://arxiv.org/html/2608.02469)
- General few-shot object detection (a related but distinct task from re-ID) reports precision/recall trade-off curves as standard practice — e.g., one 2024 method reports average precision/recall of 88.2%/79.5%, and general PR-curve/AP methodology (varying confidence or IoU threshold to trace the curve, taking area under it) is standard — but this is object *detection*, not re-identification/matching against a gallery, so it does not directly answer the open-set-matching threshold question — [Few-Shot Object Detection: Research Advances and Challenges](https://arxiv.org/html/2404.04799v1) (via search synthesis)

### Inferences
- As of this search, the strongest, most fully-documented examples of "concrete precision/recall + explicit open-set threshold rationale for a few-reference-image, streaming-relevant setting" come from the wildlife/livestock re-ID literature (cattle muzzle 2608.28663, WildFusion 2608.02469), not from generic manufactured-object re-ID. A design team building a few-reference-photo open-gallery streaming matcher would likely get more directly transferable guidance from these two papers' calibration/threshold/margin recipes than from generic object re-ID literature, which is thinner and less mature on the open-set framing specifically.
- The existence of ISAR (WACV 2024) and the 2026 kitchen-video zero-shot object re-ID paper confirms the non-person object re-ID niche is active and growing, but this pass could not extract their specific operating-point numbers — both are flagged as high-value follow-up reads.
