# Absence-Aware and Open-Set/Anomaly-Detection Framings for Few-Shot Visual Verification

## How does few-shot anomaly detection (PatchCore, WinCLIP, 2023-2025 follow-ups) build a "normal" model from a handful of reference images, and what score/threshold flags "abnormal"?

### Takeaway
The dominant paradigm is **memory-bank / nearest-neighbor matching in a pretrained feature space**: a handful of reference ("normal"/target-present) images are embedded with a frozen backbone (ResNet, CLIP, or DINOv2), stored as a small set of exemplar features, and a test image/patch is scored by its distance to its nearest stored neighbor(s); a threshold (often calibrated to a desired percentile or FAR on a held-out "normal" or background set) converts that distance into an accept/reject decision. Vision-language approaches (WinCLIP) additionally use compositional text-prompt ensembles as a zero-shot prior and blend it with the few-shot visual memory bank.

### Cited Findings
- WinCLIP (CVPR 2023, Jeong, Zou, Kim, Zhang, Ravichandran, Dabeer) does window-based CLIP alignment: "a compositional ensemble on state words and prompt templates" plus "efficient extraction and aggregation of window/patch/image-level features aligned with text"; its few-shot extension WinCLIP+ "uses complementary information from normal images" and reaches 93.1%/95.2% AUROC (classification/segmentation) on MVTec-AD with just **1 normal shot**, versus 91.8%/85.1% for the pure zero-shot version — showing that even a single reference image measurably tightens the decision boundary over prompts alone. — [WinCLIP GitHub / CVPR poster](https://github.com/SkiddieAhn/Code-WinCLIP), [CVPR poster page](https://cvpr.thecvf.com/virtual/2023/poster/22426)
- PatchCore (Roth et al., "Towards Total Recall in Industrial Anomaly Detection") stores locally-aware patch features from normal training images in a memory bank representing a "hyper-dimensional space of normality," and computes the image-level anomaly score as a **reweighted maximum nearest-neighbor distance**: s = (1 − exp‖m*_test − m*‖ / Σ_{m∈N_b(m*)} exp‖m*_test − m‖) · s*, where s* is the raw max patch-to-nearest-neighbor distance, m*_test is the most anomalous test patch, and the denominator sums over the b nearest neighbors of m* in the memory bank — this reweighting down-weights patches whose neighbors are themselves already rare/isolated, making the score more robust than raw max-distance alone. — [PatchCore paper](https://arxiv.org/pdf/2106.08265), [anomalib issue discussion](https://github.com/open-edge-platform/anomalib/issues/286)
- PatchCore "can operate in low-shot training regimes… sampling as little as 1% of the patch representations to be in the memory bank is sufficient for good performance," and only requires normal images for training. — [dataroots blog](https://dataroots.io/blog/anomaly-detection-in-images-using-patchcore), [Anomalib docs](https://anomalib.readthedocs.io/en/v2.0.0/markdown/guides/reference/models/image/patchcore.html)
- "Search is All You Need for Few-shot Anomaly Detection" (Wang et al., Apr/May 2025, arXiv:2504.11895) proposes **VisionAD**, a visual-only nearest-neighbor search over a vision-foundation-model (e.g., DINOv2-style) memory bank, explicitly arguing this simpler search-based approach beats CLIP-prompt-engineered methods; with only **1 normal support image** it reports image-level AUROC of 97.4%/94.8%/70.8% on its benchmarks, outperforming prior SOTA by +1.6/+3.2/+1.4 points. — [arXiv:2504.11895](https://arxiv.org/pdf/2504.11895), [GitHub VisionAD](https://github.com/Qiqigeww/VisionAD)
- UniVAD (CVPR 2025, arXiv:2412.03342) is a **training-free** unified few-shot model that segments an image into components (Contextual Component Clustering) and does Component-Aware Patch Matching + Graph-Enhanced Component Modeling against a few normal reference samples, achieving SOTA across nine industrial/logical/medical few-shot anomaly datasets without per-category training — evidence the field is converging on "match against a small reference set with vision-foundation features," not on training classifiers per target. — [arXiv:2412.03342](https://arxiv.org/abs/2412.03342), [GitHub](https://github.com/FantasticGNU/UniVAD)
- PromptAD (arXiv:2404.05231) instead learns prompts using **only normal samples** for few-shot anomaly detection — a complementary line that stays in the WinCLIP-style prompt-ensemble family rather than nearest-neighbor matching. — [arXiv:2404.05231](https://arxiv.org/pdf/2404.05231)
- A dedicated study, "Optimizing PatchCore for Few/many-shot Anomaly Detection" (arXiv:2307.10792), specifically investigates how PatchCore's memory-bank sizing and coreset subsampling should change when only a handful of reference ("shot") images are available, indicating the vanilla PatchCore recipe is not shot-count-invariant and needs recalibration at low shot counts. — [arXiv:2307.10792](https://arxiv.org/pdf/2307.10792)
- Thresholding practice across this literature is typically **AUROC-based during evaluation** (no single canonical operating threshold reported) but in deployment-oriented papers (e.g., the KWS literature below) the threshold is explicitly tuned to hit a target false-accept rate on a held-out negative/background set rather than a fixed statistical cutoff.

### Inferences
- The "k=3 exemplars" framing in the user's problem maps closely onto the "1-to-few-normal-shot" anomaly-detection setting; PatchCore/VisionAD-style **nearest-neighbor-to-memory-bank scoring with a reweighted/robust distance statistic** is a well-validated recipe for the "is this target-consistent" half of the problem, and it is inherently agnostic to what the "abnormal" class looks like (it never needs negative examples) — a good structural fit for "confusers are unknown and diverse."
- The strongest 2024-2025 systems (VisionAD, UniVAD) favor **self-supervised vision-foundation embeddings (DINOv2-family)** over CLIP for the visual matching itself, using CLIP/text mainly as a zero-shot prior when no images exist at all; when even 1-3 reference images exist, pure visual nearest-neighbor matching is reported to outperform prompt-based approaches.

### Gaps
- None of the sources found give a single canonical formula for converting an anomaly score into a hard "present/absent" decision threshold under a genuinely-imbalanced (mostly-absent) test distribution; the AUROC-centric evaluation culture in this literature (MVTec/VisA benchmarks) largely sidesteps explicit operating-threshold calibration, which is precisely the user's practical concern.

## What does open-set recognition literature suggest for calibrating a rejection threshold when the "known" class has only a few examples and "unknown" is everything else (diverse, not sampled during calibration)?

### Takeaway
Open-set recognition (OSR) has converged on **prototype-distance and energy-based scores with post-hoc calibration** (e.g., Relative Mahalanobis Distance, energy score at a percentile of in-distribution scores) rather than learned "unknown" classes, precisely because the unknown region cannot be sampled representatively; but a 2024 paper explicitly shows that **standard OSR evaluation/calibration protocols implicitly assume balanced known/unknown proportions and break down under realistic imbalance**, which is directly relevant to the "mostly absent" framing.

### Cited Findings
- Prototype-based OSR: "CPN was the first to introduce prototype learning to OSR, modeling known classes as prototypes and rejecting the unknown based on distance metric," and more recent distance/prototype methods "explicitly shap[e] compact known-class regions in feature or logit space, so that rejection can be performed according to geometric compatibility with class anchors or prototypes." — [ScienceDirect summary via search](https://www.sciencedirect.com/science/article/abs/pii/S0950705124005604)
- "Calibrated Open-Set Prototypes for Cross-Domain RF Emitter Recognition" (2026) converts multiple prototype-score statistics — "top score, score margin, top-score average, and score entropy" — into a calibrated known-class probability via a technique the authors call BOC (Balanced Open-set Calibration), and selects the rejection threshold via a validation set rather than a fixed geometric cutoff. — [doi.org/10.3390/electronics15143077](https://doi.org/10.3390/electronics15143077)
- A community-level evaluation of open-set plankton recognition found that "the best community-level OOD method was a prototype-distance variant rather than MSP [maximum softmax probability], even though MSP had the highest sample-level AUROC" — i.e., the best-performing score depends on which operating regime (per-sample vs. aggregate) you calibrate against, a caution directly relevant to picking a threshold metric. — [arXiv:2605.15835](https://arxiv.org/html/2605.15835v1)
- Energy-based OOD detection (Liu et al., NeurIPS 2020): the energy score E(x;f) = −T·log Σ_i e^{f_i(x)/T} is used instead of softmax confidence because it is "theoretically aligned with the probability density of the inputs and less susceptible to the overconfidence issue"; a common threshold recipe is to set the cutoff "at the 95th percentile of the in-distribution [scores]," i.e., calibrated directly off the known-class score distribution rather than any assumption about the unknown distribution. — [arXiv:2010.03759](https://arxiv.org/pdf/2010.03759), [OpenReview](https://openreview.net/pdf?id=KsN9p5qJN3)
- Mahalanobis-distance OOD detection: "the deep Mahalanobis distance (DM) is computed from layers of a trained deep classifier," but plain Mahalanobis distance "fails to outperform the baselines in the practically important few-shot setting," motivating a **covariance-corrected Mahalanobis distance** for few-shot out-of-domain detection (Amazon Science, few-shot intent detection). — [Amazon Science paper](https://assets.amazon.science/64/48/4d1e599c4472859e27a9f7647786/few-shot-out-of-domain-intent-detection-with-covariance-corrected-mahalanobis-distance.pdf)
- Relative Mahalanobis Distance (Ren et al., 2021) fixes near-OOD failure of plain Mahalanobis distance by comparing the class-specific distance to a distance computed against a single **global Gaussian fit to all in-distribution data**: RMD_k(z′) = MD_k(z′) − MD_0(z′), removing the effect of generic (class-agnostic) feature density so that the residual reflects genuine class-specific mismatch. — [search summary](https://arxiv.org/html/2510.15202v1) (citing Ren et al.); note: this is a search-engine synthesis of the Ren et al. ICML 2021 paper rather than a primary-source fetch, since the primary PDF could not be parsed directly in this session.
- Class imbalance in OSR evaluation: Komorniczak & Ksieniewicz, "Taking Class Imbalance Into Account in Open Set Recognition Evaluation" (arXiv:2402.06331, Feb 2024; published in *Neural Computing and Applications*, DOI 10.1007/s00521-024-10960-2) state that deep networks under the closed-world assumption "cannot recognize samples from unknown classes and often induce an incorrect label with high confidence," and that standard OSR evaluation protocols do not adequately account for "the impact of class imbalance, especially in the dichotomy between known and unknown samples" — i.e., most OSR benchmarks implicitly assume roughly comparable known/unknown sample counts, which does not hold in "mostly absent" deployments. — [arXiv:2402.06331](https://arxiv.org/abs/2402.06331)
- "Conformal Inference for Open-Set and Imbalanced Classification" (arXiv:2510.13037) notes that "single observations from rare classes are far more valuable than observations from common ones, and if such rare examples are placed in the calibration set rather than training, the model cannot learn to classify them" — arguing for asymmetric train/calibration splitting when the known/target class is rare, and using conformal-prediction-style coverage guarantees instead of a single fixed threshold. — [arXiv:2510.13037](https://arxiv.org/html/2510.13037)
- A 2018 OSR survey ("Recent Advances in Open Set Recognition: A Survey," arXiv:1811.08581) is a standing reference for the taxonomy (discriminative vs. generative OSR, distance-based rejection, extreme-value-theory-based calibration e.g. OpenMax) that underlies the more recent calibration-specific papers above. — [arXiv:1811.08581](https://arxiv.org/pdf/1811.08581)

### Inferences
- The literature converges on calibrating thresholds **off the known/target-class score distribution alone** (percentile-based, e.g., 95th percentile of in-distribution scores, or a validation-based rejection threshold from prototype-score statistics) precisely because the unknown/absent distribution cannot be sampled representatively — this is directly applicable to a k=3-exemplar target-verification setting: calibrate the threshold using the spread/variance among the 3 reference images (and possibly augmentations of them) rather than trying to model "everything else."
- The 2024 class-imbalance-in-OSR-evaluation finding is an important corrective: reporting AUROC/F1 under an implicit 50/50 known/unknown test split (as most OSR benchmarks do) will not predict real-world precision when unknowns vastly outnumber knowns — precision at a fixed threshold degrades sharply as the known:unknown ratio drops, so evaluation protocols (and threshold selection) should be re-run under the actual expected prevalence, not a balanced benchmark split.

### Gaps
- No source found gives a closed-form recipe for how much a rejection threshold should shift purely as a function of expected target prevalence (e.g., "target present in 1% of frames") — the imbalance papers found argue this matters and propose evaluation/calibration-split fixes, but do not give an explicit prevalence-to-threshold-shift formula that could be applied directly to a k=3 visual verification system.

## Are there techniques specific to the "target usually absent" class-imbalance framing (camera-trap re-ID, wake-word FAR suppression, single-target visual search)?

### Takeaway
Yes — three independent domains that share the "mostly absent, decide per-instance, few reference exemplars" structure (camera traps, wake-word/KWS, cognitive visual search) converge on the same practical pattern: **(1) a cheap high-recall/high-FAR first-stage filter, (2) a stricter second-stage verifier tuned to a fixed low false-accept rate against a "typical negative" background set, and (3) explicit reporting of accuracy at a fixed FAR (not AUROC alone) because prevalence is extreme.**

### Cited Findings
- **Camera traps (MegaDetector):** "In typical camera trap deployments, 70–95% of frames are empty, triggered by wind, rain, or moving vegetation." MegaDetector assigns each detection a confidence score in [0,1] and a threshold (practically **0.15–0.3**) is applied; "a high threshold increases the false negative rate (FNR), whereas a low threshold raises the false positive rate (FPR)," and practitioners explicitly accept more false positives (lower threshold) to avoid missing rare true animal events, deferring precision cleanup to a second stage. — [MegaDetector GitHub](https://github.com/microsoft/MegaDetector/blob/main/README.md), [Microsoft AI for Good](https://microsoft.github.io/MegaDetector/)
- A 2026 paper on empty-camera-trap-image recognition reports that MegaDetector-optimization methods achieved **FNR of 1.4–4.0% and FPR of 0.3–0.9%**, a substantial improvement over "traditional threshold regulation" alone — evidence that a single global threshold on a detector confidence score is inferior to learned/optimized empty-frame filtering when frames are overwhelmingly negative. — [PMC13509521](https://pmc.ncbi.nlm.nih.gov/articles/PMC13509521/), [MDPI](https://www.mdpi.com/2076-2615/16/16/2609)
- **Camera-trap re-ID / open-set individual recognition:** a practical wildlife-ID model "must handle verification and re-identification of known individuals and remain robust when confronted with entirely new ones, a setting referred to as open-set recognition," and recent work shows self-supervised ViTs (DINO/DINOv2) trained on unlabeled camera-trap footage "learn feature spaces that support retrieval, clustering, and few-shot transfer without manual labels, with metric structure well suited to open-set verification" — i.e., embedding-space nearest-neighbor verification (same family as PatchCore/VisionAD) is the preferred technique when only a handful of labeled reference images per individual/species exist. — [Self-supervised camera-trap face embedder, arXiv:2507.10552](https://arxiv.org/pdf/2507.10552)
- **Keyword spotting / wake-word (closest documented analogue to k-shot visual absence detection):** Rusci & Tuytelaars, "Few-Shot Open-Set Learning for On-Device Customization of KeyWord Spotting Systems" (Interspeech 2023, arXiv:2306.02161) explicitly frame the problem as: given K enrollment (support) samples per new keyword, decide keyword-present vs. unknown/background. They test three open-set classifiers: **openNCM** (nearest-class-mean prototype using K random target-domain samples to also estimate an "unknown" prototype), **OpenMAX** (fits Weibull distributions to per-class distances from K enrollment samples, extreme-value-theory calibration), and **Dummy Proto** (jointly trained generator producing synthetic "unknown" prototypes). Decision rule: predict class i if p_i ≥ γ else predict "unknown," where **γ is explicitly tuned to hit a fixed 5% False Acceptance Rate on a held-out negative (GSC−) dataset** — not a fixed statistical threshold. At **10-shot**, best config (Triplet Loss + openNCM) reaches 76% accuracy with 21% false-rejection-rate at that fixed 5% FAR (AUROC 0.94); at **5-shot**, 71% accuracy with 26% FRR at 5% FAR — demonstrating a clean, directly-transferable "accuracy-at-fixed-FAR vs. shot count" curve. — [arXiv:2306.02161 via ar5iv](https://ar5iv.labs.arxiv.org/html/2306.02161)
- Practical wake-word engineering rule of thumb: "a false-accept rate of less than 0.5 per hour and a false-reject rate of less than 5% is often considered reasonable in practice," and FAR is treated as "a privacy metric as well as a usability one" — underscoring that in a mostly-absent regime, the operating metric of interest is an **absolute rate per unit exposure** (per hour, per frame-stream) rather than a percentage of a balanced test set. — [Picovoice wake word guide](https://picovoice.ai/blog/complete-guide-to-wake-word/)
- **Cascaded/two-stage verification** is standard in production wake-word systems: "If a fast rejection classifier stage accepts an image [or audio segment] as a match, it is 'provisionally' accepted and passed to one or more secondary classifier stages for final acceptance or rejection," with the first stage deliberately tuned to have a "relatively high false acceptance rate" (favoring recall) so it is fast, while the secondary, more expensive classifier drives the false-accept rate down before final commit. Apple's "Hey Siri" is documented as using "two stages with possible normal and second-chance thresholds on a trade-off curve," and cascaded hotword detection to push false-alarm rates "as low as one per week." — [Cascading classifiers (Wikipedia)](https://en.wikipedia.org/wiki/Cascading_classifiers), [Apple ML Research: Hey Siri](https://machinelearning.apple.com/research/hey-siri), [Apple ML Research: Personalized Hey Siri](https://machinelearning.apple.com/research/personalized-hey-siri), [Progressive Voice Trigger Detection: Accuracy vs Latency, arXiv:2010.15446](https://arxiv.org/pdf/2010.15446)
- **Single-target visual search (cognitive science):** In target-present/target-absent visual search tasks, "the visual item is first selected by attention and then tested against the representation of the target in memory... If the visual item does not match, a new visual item may be selected and the process is repeated, or the search ends, declaring the target to be absent"; critically, human observers calibrate their absent/present decision criterion using **global target prevalence over a long block rather than local/recent prevalence** — i.e., humans track a long-run base rate rather than reacting to the last few trials, which is suggestive for setting priors/thresholds off long-run expected target frequency rather than recent-window statistics. — [Attention/Psychophysics review](https://link.springer.com/article/10.3758/s13414-024-02906-6) (general visual-search template-matching literature)
- **Few-shot open-set object detection with class imbalance framing:** Su, Zhang, Li, Zhou, "Towards Generalized Few-Shot Open-Set Object Detection" (arXiv:2210.15996, orig. Oct 2022, revised Feb 2024; also published as G-FOOD in IEEE TIP 2024) address the specific failure mode that "few training samples induce the model to overfit on the known classes, resulting in a poor open-set performance" — i.e., few-shot conditions make open-set rejection *harder*, not easier, because the known-class region is poorly estimated. Their FOOD method uses a Class Weight Sparsification Classifier (CWSC, "randomly sparsifies normalized weights to reduce co-adaptability") and an Unknown Decoupling Learner (UDL) that identifies unknowns "without any threshold, prototype, or generation," achieving 4.80-9.08% F-score improvement for unknown-class rejection over prior open-set detectors across few-shot regimes on VOC→COCO. — [arXiv:2210.15996](https://arxiv.org/abs/2210.15996)

### Inferences
- All three domains (camera traps, wake-word, few-shot OSOD) independently reinvent a **two-stage recall-then-precision cascade** as the practical answer to "mostly absent + must decide per-instance": a cheap, generous first pass minimizes missed targets, and a second, stricter pass (nearest-neighbor-to-exemplar distance, Weibull/EVT-calibrated prototype distance, or a dedicated unknown-decoupling classifier) is explicitly calibrated against a **fixed false-accept-rate budget on a representative negative/background set**, not against a theoretical threshold. This is the single most transferable, well-evidenced pattern for the k≈3 exemplar visual-verification problem.
- The KWS false-accept-rate-vs-shot-count data (arXiv:2306.02161) is the most directly quantitative and transferable precedent found: it shows diminishing but still meaningful accuracy gains from 5-shot to 10-shot at a fixed FAR, suggesting that k=3 exemplars is on the steep part of that curve and that threshold/FAR should be set conservatively (favoring rejection) at such low shot counts.
- MegaDetector's practice of deliberately using a low, recall-favoring threshold (0.15-0.3) and pushing precision improvement to downstream/second-stage processing — rather than trying to find one threshold that is simultaneously high-precision and high-recall on a single detector score — is a directly applicable design lesson.

### Gaps
- I found strong quantitative FAR-vs-shot-count data for audio keyword spotting but did not find an equivalently quantitative "AUROC/precision vs. shot-count vs. target-prevalence" table for any *purely visual* few-shot absence/verification system; the visual anomaly-detection papers (section 1) report AUROC on roughly balanced benchmarks, not precision under realistic (very low) target prevalence.
- The single-target visual-search (cognitive-science) literature describes qualitative human decision strategies (prevalence-based criterion setting) but I did not find a source translating this into an explicit quantitative Bayesian-updating or SPRT-style algorithm citable for a computational system — this connects to the temporal-evidence question below but remains a gap for the "absence" framing specifically.

## What role does temporal/sequential evidence accumulation (SPRT, Bayesian online changepoint detection, "N consecutive weak signals") play, vs. a simple z-score threshold or hard consecutive-hit counter?

### Takeaway
Sequential hypothesis testing (SPRT) is the theoretically optimal method for minimizing the number of observations needed to reach a decision at fixed error rates and is used in vision/detection pipelines (e.g., RANSAC model verification) and fault/anomaly detection; production wake-word systems in practice implement a simplified, non-optimal but robust proxy — **posterior smoothing + a minimum-consecutive-frames-above-threshold rule** — which is easier to tune and deploy than full SPRT but sacrifices its optimality guarantees. Bayesian online changepoint detection (BOCPD) is the relevant framework when "evidence" is about a regime shift (target newly present) rather than a static hypothesis test, but it trades detection latency for confidence, and identified changepoints "inevitably lag slightly behind the actual structural breaks."

### Cited Findings
- SPRT definition and optimality: "The sequential probability ratio test (SPRT) is a statistical testing scheme that minimizes sensing time by allowing for a variable number of samples, where samples are taken sequentially and compared against two thresholds to determine which hypothesis to accept... It is optimal in minimizing the average number of samples required for a given detection performance." Unlike a fixed-sample test, SPRT "works in an online fashion; it updates the corresponding statistical measure as samples arrive sequentially, and can conclude when sufficient samples have arrived to reach a decision." — [ScienceDirect Topics: SPRT overview](https://www.sciencedirect.com/topics/engineering/sequential-probability-ratio-test)
- SPRT applications directly relevant to vision/detection: "the technique has been adapted for time-constrained vision problems, including use with RANSAC (Random Sample Consensus) model evaluation by setting the probability of rejecting a 'good' sample to achieve maximum speed of the whole RANSAC process," and more generally "SPRT is a powerful method of testing an alternative hypothesis (the abnormal mode) against a null hypothesis (the normal mode)... determin[ing] whether the hypothesis has been accepted, rejected, or if further information is required," making it directly applicable to online anomaly detection. (Primary source: Matas & Chum's "Wald's Sequential Analysis for Time-Constrained Vision Problems" chapter was located but could not be parsed as text in this session — its content is referenced here via secondary search-result summary, flagged as lower-confidence sourcing pending direct verification.) — [search summary citing Matas/Chum chapter](https://cmp.felk.cvut.cz/ftp/articles/matas/matas-wald-lncs08.pdf), [ScienceDirect: SPRT for process safety monitoring](https://www.sciencedirect.com/science/article/abs/pii/S0957582013000086)
- Bayesian Online Changepoint Detection (Adams & MacKay, 2007, as characterized by recent citing work): BOCPD "maintain[s] a posterior distribution over the current run length — the number of observations since the most recent change-point," updated online via message-passing "rather than waiting for the full sequence." Critically, "the model requires the accumulation of sufficient posterior evidence from new observations to confidently signal a regime shift, and consequently, the identified changepoints inevitably lag slightly behind the actual structural breaks." — [ResearchGate: Bayesian Online Changepoint Detection](https://www.researchgate.net/publication/1771282_Bayesian_Online_Changepoint_Detection), [arXiv:2508.06385 (extension to collective anomalies)](https://arxiv.org/pdf/2508.06385)
- A 2026 streaming intrusion-detection paper ("CALIBURN: Operationally Calibrated Streaming Intrusion Detection with Regime-Dependent Conformal Risk Control," arXiv:2605.24696) combines changepoint-style regime detection with conformal risk control to get operationally-calibrated online decisions, illustrating that recent work explicitly pairs sequential/regime-aware detection with formal calibration guarantees rather than ad hoc thresholds — a direct precedent for combining BOCPD-style reasoning with an OSR-style calibrated threshold. — [arXiv:2605.24696](https://arxiv.org/pdf/2605.24696)
- Production wake-word posterior smoothing (the practical, non-SPRT baseline actually deployed): "The wakeword model outputs a wakeword posterior, which is processed using a posterior-smoothing and peak detection component to remove or reduce spikes... A wakeword is detected if the smoothed wakeword posteriors are greater than the threshold for a certain amount of time, such as 500 milliseconds... ensuring that an erroneous single-frame increase of the average above the threshold does not trigger detection." A concretely cited practical rule: **"If P(Keyword) > 0.8 for 3 consecutive frames, trigger."** — [search synthesis of wake-word patents/engineering sources](https://www.arunbaby.com/speech-tech/0040-wake-word-detection/), [Povey ICASSP 2021 streaming transformer wake word](https://www.danielpovey.com/files/2021_icassp_transformer_wake_word.pdf)
- Cascaded/two-stage detection (see previous section) is itself a form of coarse sequential evidence accumulation: a fast, lenient first-stage "provisional accept" is only confirmed after a second, independent, stricter verification pass — functionally similar to requiring two independent pieces of corroborating evidence before committing, though not framed by its authors as SPRT. — [Cascading classifiers](https://en.wikipedia.org/wiki/Cascading_classifiers), [Progressive Voice Trigger Detection, arXiv:2010.15446](https://arxiv.org/pdf/2010.15446)

### Inferences
- The practical wake-word industry pattern (**posterior smoothing + minimum-consecutive-frames rule**, e.g., "3 consecutive frames above 0.8") is best understood as a simplified, fixed-window approximation to SPRT: SPRT would use a variable number of samples and formally trade off the two error thresholds A and B (related to desired false-accept rate α and false-reject rate β), while the consecutive-hit counter uses a fixed window and single per-frame threshold — cheaper to implement and reason about, but not adaptive to signal strength (a very strong single-frame signal gets no "credit" toward an early decision, and a borderline signal held just under threshold for N+1 frames never triggers even though cumulative evidence may exceed what SPRT would require).
- For "target usually absent," SPRT's asymmetric-threshold design (independently controllable α = false-accept and β = false-reject bounds, translating directly into the two SPRT boundaries A ≈ (1−β)/α and B ≈ β/(1−α) in the classical Wald formulation) is structurally well-matched to a scenario where false accepts must be suppressed far more aggressively than false rejects — more so than a symmetric z-score threshold, which does not by default treat the two error types asymmetrically or accumulate evidence across frames.
- BOCPD is conceptually the right tool when "presence" is modeled as a regime (a run of frames where the underlying generative process shifted from "background" to "target-present"), but its acknowledged latency cost (changepoints lag true onset because posterior evidence must accumulate) means it trades early-detection speed for confidence — the same fundamental trade-off SPRT makes explicit via its α/β thresholds, and the same trade-off a consecutive-hit counter makes implicitly via its window length N.

### Gaps
- I was unable to directly extract full text from the primary Matas & Chum "Wald's Sequential Analysis for Time-Constrained Vision Problems" source (PDF parsing failed in this session), so the SPRT-for-vision claims above rely on secondary search-result summaries rather than a verified primary-source read; a follow-up direct read of this chapter (or the original Matas/Šochman RANSAC-SPRT paper, "Matas & Chum, Randomized RANSAC with Td,d test") would strengthen this section.
- No source found gives a head-to-head empirical comparison (on the same dataset/task) of SPRT vs. Bayesian online changepoint detection vs. a hard consecutive-hit counter for a visual absence/presence decision specifically — the comparison above is an inference from each method's general properties, not a cited empirical result.
- No source explicitly discusses combining SPRT-style sequential testing with a *few-shot, prototype-distance* per-frame likelihood (i.e., using an OSR/anomaly score as the per-frame observation fed into an SPRT accumulator) — this appears to be an open combination not yet covered by a named paper in the literature surveyed.

## Are there recent (2023-2025) papers explicitly studying "few-shot presence detection" or "few-shot open-set object verification" as a named problem, and what precision-focused techniques do they use?

### Takeaway
The closest explicitly-named formulations found are **"Generalized Few-Shot Open-Set Object Detection" (G-FOOD, 2022/2024)** and **"Boosting Few-Shot Open-Set Object Detection via Prompt Learning and Robust Decision Boundary" (2024)** in vision, and **"Few-Shot Open-Set Learning for On-Device Customization of KeyWord Spotting Systems" (2023)** in audio — all three frame the task exactly as "verify a specific target class from a handful of examples, reject everything else, and do not let scarce data compromise the unknown-rejection boundary," and all three use decision-boundary/threshold techniques (sparsified classifiers, robust decision boundaries, or FAR-calibrated prototype thresholds) rather than training on large negative sets.

### Cited Findings
- Su, Zhang, Li, Zhou, "Towards Generalized Few-Shot Open-Set Object Detection" (arXiv:2210.15996; extended/published as G-FOOD, IEEE Transactions on Image Processing 2024, DOI 10.1109/TIP.2024.3364495) is explicitly framed around the failure mode that few-shot conditions *worsen* open-set rejection quality (overfitting to the sparse known-class samples), and reports F-score gains of 4.80-9.08% for unknown-class detection specifically under few-shot regimes on VOC/COCO splits — this is the most directly named "few-shot open-set object detection" precedent found. — [arXiv:2210.15996](https://arxiv.org/abs/2210.15996), [IEEE/ACM DOI](https://dl.acm.org/doi/abs/10.1109/TIP.2024.3364495)
- "Boosting Few-Shot Open-Set Object Detection via Prompt Learning and Robust Decision Boundary" (arXiv:2406.18443, June 2024) is a follow-up in the same named sub-area (few-shot open-set object detection), using prompt learning together with an explicitly "robust decision boundary" mechanism — the title itself signals that decision-boundary robustness under scarce known-class data is treated as the central technical problem. — [arXiv:2406.18443](https://arxiv.org/pdf/2406.18443)
- "Cross-Domain Few-Shot Object Detection via Enhanced Open-Set Object Detector" (ECCV 2024) extends the same named line of work (CD-FSOD) to the case where the few-shot target domain is *also* different from the training domain, adding domain shift on top of the few-shot + open-set combination. — [ECCV 2024 paper](https://dl.acm.org/doi/abs/10.1007/978-3-031-73636-0_15)
- "UADet: A Remarkably Simple Yet Effective Uncertainty-Aware Open-Set Object Detection Framework" (arXiv:2412.09229, Dec 2024) is a related contemporaneous open-set object detection paper using uncertainty-awareness for the known/unknown decision, though not explicitly badged "few-shot" in the title. — [arXiv:2412.09229](https://arxiv.org/pdf/2412.09229)
- Rusci & Tuytelaars, "Few-Shot Open-Set Learning for On-Device Customization of KeyWord Spotting Systems" (Interspeech 2023, arXiv:2306.02161) is the clearest **named, precision/FAR-focused** instance of exactly this problem outside vision: it is explicitly scoped as verifying a user-specified target class from K enrollment (support) examples while suppressing false accepts from an open, unsampled "everything else" distribution, evaluated at a fixed 5% FAR operating point rather than AUROC alone (see details and numeric results in the earlier "target usually absent" section above). — [arXiv:2306.02161](https://ar5iv.labs.arxiv.org/html/2306.02161)
- The precision-focused techniques common to this named cluster of 2023-2025 papers are: (a) **explicit unknown-class decoupling/sparsification** to prevent the known-class decision region from over-fitting to few examples (FOOD's CWSC + UDL); (b) **prompt learning combined with a robustness-regularized decision boundary** (arXiv:2406.18443); and (c) **FAR-calibrated prototype/Weibull thresholds tuned on a held-out negative set** (KWS paper). None of the papers found rely on a fixed, uncalibrated distance cutoff; all treat threshold/boundary calibration against scarce known-class data as the core research contribution, not an afterthought.

### Inferences
- "Few-shot open-set object *detection*" (as a named sub-field) is well-established for the localization+classification task (find and label unknown objects in a scene with abundant unknowns), but none of the papers found are framed as pure **binary image/frame-level presence verification** ("is my one target class present anywhere in this frame, yes/no, given k reference images") — the closest match is the KWS literature, which is binary/verification-style by construction (a keyword is either uttered or not) rather than the multi-object-detection framing of the vision papers.
- This suggests a **naming gap**: "few-shot presence detection" or "few-shot open-set verification" for a *single* target class against a diverse, unsampled background is not yet a standardized named problem in the vision literature the way "few-shot open-set object detection" (multi-class, multi-unknown) or "open-set/few-shot keyword spotting" (audio, binary) are. A system built for the user's k=3-exemplar visual absence/presence problem would need to adapt techniques from (1) few-shot anomaly detection (nearest-neighbor-to-memory-bank scoring), (2) OSR calibration-under-imbalance (FAR-based threshold tuning, RMD-style class-conditional normalization), and (3) the KWS verification playbook (cascade + fixed-FAR threshold + consecutive-frame confirmation), rather than adopting a single off-the-shelf paper.

### Gaps
- I did not find a paper that uses the exact phrase "few-shot presence detection" as a named problem in the 2023-2025 window; the closest terminology clusters are "few-shot open-set object detection" (vision, multi-class) and "few-shot open-set learning for keyword spotting" (audio, binary/verification). This is worth flagging explicitly to the report writer as a terminology/coverage gap rather than an oversight in search — several query variations were tried without finding a closer vision-specific match.
- No source found explicitly benchmarks a vision system on frame-level (not per-object-box) presence/absence with a genuinely low target-prevalence test set (e.g., target present in <5% of evaluation frames) and reports precision/recall at that realistic prevalence — nearly all vision benchmarks found (MVTec-AD, VisA, VOC/COCO open-set splits) use roughly balanced or moderately-imbalanced test distributions, which is the same evaluation-protocol gap identified in the OSR class-imbalance section above.
