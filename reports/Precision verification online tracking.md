# Gated cascades beat blended global scores

Across visual object tracking, open-set re-identification, conformal statistics, and few-shot anomaly detection, the 2022–2025 literature converges on one dominant precision-suppression architecture: a **cheap, generous first-stage gate followed by a stricter, structurally-verified second stage**, with updates to any persistent memory (template, gallery, threshold) themselves gated on a confidence-and-corroboration check — never a single blended score. Concretely, distractor-aware trackers like KeepTrack and DAM4SAM suppress false re-detections by tracking candidate identity over time and gating memory writes on reliability thresholds, not by fusing appearance and motion into one number ([DAM4SAM, arXiv:2411.17576](https://arxiv.org/html/2411.17576v2)); online conformal prediction (ACI, PID-control, SAOCP) gives a formally self-adjusting threshold but is proven to degrade under the exact conditions a target-mostly-absent tracker has — severe class imbalance and self-labeled (ground-truth-free) feedback — unless explicitly corrected ([arXiv:2605.20515](https://arxiv.org/html/2605.20515v1)); few-shot anomaly detection and open-set recognition both calibrate thresholds off the known/target class alone and reject a fixed false-accept budget against a representative negative pool, exactly the two/three-shot regime the project has to work with ([WinCLIP, CVPR 2023](https://cvpr.thecvf.com/virtual/2023/poster/22426); [Rusci & Tuytelaars, arXiv:2306.02161](https://ar5iv.labs.arxiv.org/html/2306.02161)); and open-gallery re-ID suppresses false matches with margin-over-runner-up checks plus quarantined, bounded, corroboration-gated gallery growth rather than unrestricted online accumulation ([Casao et al., Sensors 2023](https://pmc.ncbi.nlm.nih.gov/articles/PMC10007633/)). No paper was found that explicitly fuses a global aggregate statistic with a local graph/cluster structure as a named verification architecture — but the adjacent "reject-option" theory of classifier cascades explains exactly why the project's own DAVE-style per-keyframe spectral-clustering verification underperformed a global adaptive threshold: clustering is a purely local, per-image decision with no population-level context, and local rejectors are known to only match — not beat — a well-calibrated global threshold once the classifier is already reasonably strong, while providing no defense against the dominant failure mode when most frames contain zero true instances ([Fischer, Hammer & Wersing, arXiv:1503.06549](https://arxiv.org/html/1503.06549)). The engineering implication is that precision-focused verification for a genuinely-absent-most-of-the-time target should be built as a gated cascade — global recall-favoring pre-filter, then local few-shot structural match, then a corroboration-gated memory update — rather than as a single fused score or an ungated clustering step run on every frame.

## Distractor-aware trackers gate memory writes, they don't blend scores

The lineage from DaSiamRPN (2018) through DiMP, KeepTrack, and 2024–2025 memory-based trackers (DAM4SAM/SAM2.1++, ODR-Net) shows a consistent shift from "make the appearance embedding more discriminative" toward "explicitly track the *identity* of distractor candidates over time, not just the target," treating single-frame appearance similarity as necessary but not sufficient. KeepTrack propagates the identities of *all* candidate objects (not just the top-scoring one) frame-to-frame using a graph-based Candidate Embedding Network solved via Sinkhorn matching, and is trained once, class-agnostically, so it generalizes to arbitrary instances from only the standard one-shot initialization template — a direct match to a "no target-class training data" deployment constraint ([KeepTrack, arXiv:2103.16556](https://arxiv.org/html/2103.16556)). DAM4SAM (CVPR 2025) is fully training-free: it splits memory into a Recent Appearance Memory (last 3 target frames) and a Distractor Resolving Memory populated only from anchor frames the tracker itself flags online via an introspection check (divergence between SAM2's primary and alternative hypothesis masks exceeding a bounding-box-ratio threshold θ_anc = 0.7), giving 4–11% robustness gains with zero retraining across SAM2 variants, EfficientTAM, and EdgeTAM ([DAM4SAM, arXiv:2411.17576](https://arxiv.org/html/2411.17576v2)). Critically, DAM4SAM's memory writes are **dual-gated**: Distractor Resolving Memory anchors are only committed when predicted IoU exceeds 0.8 *and* mask area stays within 20% of the recent median, and a journal-extension ablation confirms that removing this reliability gate and updating on distractor-detection alone causes "tracking quality [to drop] significantly" — direct evidence that an ungated update is how a false positive hijacks the tracker for a sustained stretch ([Distractor-Aware Memory-Based VOT, arXiv:2509.13864](https://arxiv.org/html/2509.13864)). Siam R-CNN's Tracklet Dynamic Programming Algorithm makes the same point from a different angle: distractors "can be consistently suppressed, which would not be possible using only visual similarity," because spatio-temporal tracklet continuity is fused with appearance in a dynamic-programming selection over the full history, not a per-frame weighted sum ([Siam R-CNN, arXiv:1911.12836](https://arxiv.org/abs/1911.12836)). Plain one-shot transformer trackers (SeqTrack, ToMP) are repeatedly flagged in the survey literature as lacking any dedicated distractor/re-detection module at all — the failures these add-on mechanisms retrofit are architectural absences, not weak appearance models ([Deep Dive into Generic Object Tracking, arXiv:2507.23251](https://arxiv.org/html/2507.23251v1)).

The anti-drift template-update literature reinforces the same "gate, don't blend" pattern for deciding *when not to update*. DAM4SAM's Recent Appearance Memory is simply not updated when the predicted mask is empty (target judged absent); AiATrack maintains a fixed long-term template alongside a short-term one that is the only component allowed to drift, so a bad update corrupts at most the fast-adapting half of the reference; STARK and MixFormer use a learned confidence head to gate which candidate crops are trusted enough to replace the dynamic template; and DiMP rate-limits its own classifier update to every 20th frame rather than every frame ([Deep Dive into Generic Object Tracking, arXiv:2507.23251](https://arxiv.org/html/2507.23251v1)). KeepTrack's memory eviction is confidence-weighted rather than FIFO — it drops the sample with smallest age×confidence product, so low-confidence detections are suppressed from ever entering the update set in the first place ([KeepTrack, arXiv:2103.16556](https://arxiv.org/html/2103.16556)). No source surveyed found a standardized metric that isolates "duration of a false-positive hijack" as a first-class quantity distinct from failure count — VOT's EAO weights early failures more than late ones, which is a related but different sensitivity — so the field's answer to long hijacks is a converging set of engineering countermeasures (confidence-gated search-mode switching, dual/gated memories, periodic-not-per-frame updates) rather than a measured target ([VOT Toolkit docs](https://vot-toolkit.readthedocs.io/en/latest/overview.html)). For a candidate-verification step embedded in a tracker, the transferable pattern is: treat a positive verification as provisional, require a reliability/agreement gate before it is allowed to update any persisted state, and keep a protected long-term anchor (the original 2–3 reference images) that a corrupted fast-adapting component can never overwrite.

## Online conformal thresholds self-adjust but break under imbalance and self-labeled feedback

Adaptive Conformal Inference (ACI) and its 2023–2024 successors reframe online threshold-setting as a gradient-descent control loop: after each frame's outcome is (even approximately) known, the threshold's implicit significance level α_t is nudged by a step proportional to whether the last decision was wrong, giving a provable long-run error-rate guarantee without distributional assumptions and requiring only O(1) memory per step ([Gibbs & Candès, NeurIPS 2021](https://papers.neurips.cc/paper/2021/file/0d441de75945e5acbc865406fc9a2559-Paper.pdf)). The 2024 JMLR follow-up removes ACI's main weakness — needing to hand-tune the step size to an unknown drift rate — by adapting the step size itself, and SAOCP (ICML 2023) extends the guarantee to hold over *every* sub-interval of the stream simultaneously, not just the long-run average, which matters for video because a long, localized false-positive hijack can be masked by an otherwise-good long-run average error rate ([Gibbs & Candès, JMLR 2024](https://www.jmlr.org/papers/v25/22-1218.html); [Bhatnagar et al., arXiv:2302.07869](https://arxiv.org/pdf/2302.07869)). Conformal PID control adds a "derivative"/scorecaster term that forecasts short-term seasonality or trend on top of the ACI-style integral correction, and Conformal Risk Control generalizes the same idea to any monotone loss (including false-negative or false-positive rate), letting a practitioner specify a target risk level directly ([Angelopoulos, Candès & Tibshirani, arXiv:2307.16895](https://arxiv.org/abs/2307.16895); [Conformal Risk Control, arXiv:2208.02814](https://arxiv.org/pdf/2208.02814)). A closely related but independently developed toolset, online false-discovery-rate control (LORD, SAFFRON), targets exactly (false accepts)/(total accepts) — closer to precision-of-the-accepted-set than ACI's per-frame miscoverage framing — and has documented robustness to the positive dependence between sequential test statistics that consecutive video frames exhibit ([Ramdas et al., SAFFRON, PMLR v80](http://proceedings.mlr.press/v80/ramdas18a/ramdas18a.pdf); [Fisher, Biometrical Journal 2024](https://onlinelibrary.wiley.com/doi/abs/10.1002/bimj.202300177)). SAFEVPR is the closest located analogue to a streaming re-detection verifier: it builds a patch-level conformal predictor over DINOv2 features with a ~90% coverage guarantee and explicitly uses **temporal consistency across consecutive frames to reject false positives while preserving the statistical guarantee**, processing sequential query images frame-by-frame ([SAFEVPR, arXiv:2605.28048](https://arxiv.org/pdf/2605.28048)).

These guarantees, however, rest on assumptions that a genuinely-absent-most-of-the-time, no-ground-truth verification step violates in two compounding ways. First, class imbalance: a marginal (non-class-conditional) conformal guarantee can be satisfied almost entirely by getting the majority (target-absent) class right while giving near-useless coverage on the rare positive class — one cited case shows coverage on the minority/anomaly class dropping to roughly 53% at a 1:345 imbalance ratio unless class-conditional (Mondrian) calibration is used, which restored 90.6% coverage ([MDPI Class-Conditional Conformal Prediction, summarized via search](https://www.mdpi.com/2504-4990/8/7/190)). Second, and more consequentially, is corrupted feedback: because a live tracker has no ground truth, any online-conformal threshold update must use the system's *own* accept/reject decisions as a proxy for correctness — precisely the scenario a 2026 paper analyzes directly, showing that standard online conformal prediction's normally-O(1/T) miscoverage bound degrades to include a term proportional to the corruption rate, i.e., **a persistent, non-vanishing bias in the operating threshold rather than merely added noise** ([Online Conformal Prediction with Corrupted Feedback, arXiv:2605.20515](https://arxiv.org/html/2605.20515v1)). That paper's proposed fixes — a filtering variant (F-ROCP) that exploits known gradient-direction information when the threshold exits its valid range, and an active-compensation variant (AC-ROCP) that periodically forces boundary values to estimate and correct the corruption pattern — are the most directly relevant mitigations found for a self-labeled deployment, restoring a vanishing-error guarantee under bounded-memory adversarial corruption. Practically, this means a naive "update the threshold using my own last few accept/reject calls" loop should be expected to converge to a systematically wrong (not just noisier) operating point, and any conformal or EWMA/CUSUM-style online threshold in this pipeline needs either an independent, even if weak or infrequent, source of ground-truth-adjacent feedback (e.g., short-horizon track continuity or a secondary, slower verifier) or an explicit corruption-compensation mechanism layered on top — a plain ACI loop closing on its own decisions is not safe to deploy as-is.

## Few-shot anomaly detection and open-set recognition treat absence as the default case

Few-shot anomaly detection is architecturally the closest-matched literature to a 2–3-reference-image, target-usually-absent verification problem, because it never requires negative/abnormal examples at all: a handful of "normal" reference images are embedded with a frozen backbone and a test patch is scored by distance to its nearest stored neighbor. PatchCore computes a **reweighted maximum nearest-neighbor distance** that down-weights patches whose neighbors are themselves already isolated in the memory bank, and works with as little as 1% coreset sampling ([PatchCore, arXiv:2106.08265](https://arxiv.org/pdf/2106.08265)); WinCLIP shows that even a **single normal shot** measurably tightens the decision boundary over zero-shot text prompts alone (93.1%/95.2% vs. 91.8%/85.1% AUROC on MVTec-AD) ([WinCLIP, CVPR 2023](https://cvpr.thecvf.com/virtual/2023/poster/22426)); and 2025 systems VisionAD and UniVAD both favor pure DINOv2-style visual nearest-neighbor search over CLIP-prompt engineering once even one reference image exists, with VisionAD reporting 97.4%/94.8%/70.8% AUROC from a single normal support image and outperforming prior SOTA by 1.4–3.2 points ([VisionAD, arXiv:2504.11895](https://arxiv.org/pdf/2504.11895); [UniVAD, arXiv:2412.03342](https://arxiv.org/abs/2412.03342)). None of this literature, however, gives a canonical recipe for converting a distance score into a hard present/absent decision under genuine, extreme prevalence imbalance — the field evaluates almost exclusively on AUROC over roughly balanced benchmarks, sidestepping the exact operating-threshold question this project needs answered.

Open-set recognition supplies the missing calibration principle: threshold cutoffs should be calibrated **off the known/target-class score distribution alone** — e.g., the 95th percentile of in-distribution energy scores, or Relative Mahalanobis Distance, which subtracts a global class-agnostic Gaussian fit to remove generic feature-density effects before comparing to a class-specific prototype — precisely because the unknown/absent distribution cannot be sampled representatively ([Energy-based OOD, arXiv:2010.03759](https://arxiv.org/pdf/2010.03759); [Relative Mahalanobis Distance, summarized via arXiv:2510.15202](https://arxiv.org/html/2510.15202v1)). A 2024 paper is a direct corrective for this project's framing: standard OSR evaluation protocols implicitly assume roughly balanced known/unknown test proportions, and precision at a fixed threshold degrades sharply as the known:unknown ratio drops below that assumption — evaluation and threshold selection need to be re-run under the actual expected prevalence, not a balanced benchmark split ([Komorniczak & Ksieniewicz, arXiv:2402.06331](https://arxiv.org/abs/2402.06331)). Three independent applied domains that share the "mostly absent, decide per-instance, few reference exemplars" structure — camera-trap detection, wake-word/keyword spotting, and few-shot open-set object detection — converge on the identical practical answer: a cheap, high-recall/high-false-accept-rate first-stage filter, followed by a stricter second-stage verifier explicitly calibrated to a fixed false-accept-rate budget on a representative negative/background set, not a theoretical cutoff. MegaDetector deliberately runs at a low, recall-favoring confidence threshold (0.15–0.3) precisely because 70–95% of camera-trap frames are empty, pushing precision cleanup downstream rather than trying to find one threshold that is simultaneously high-precision and high-recall ([MegaDetector](https://github.com/microsoft/MegaDetector/blob/main/README.md)). The keyword-spotting literature gives the single most quantitatively transferable precedent: with K enrollment (support) samples per target keyword and an explicit rejection threshold γ tuned to hit a fixed 5% false-accept rate on a held-out negative set, a 10-shot configuration reaches 76% accuracy at 21% false-reject rate (AUROC 0.94), and a 5-shot configuration reaches 71% accuracy at 26% false-reject rate at the same 5% FAR — showing k≈3 exemplars sits on the steep part of the shot-count curve and that the threshold should be set conservatively (favoring rejection) at such low counts ([Rusci & Tuytelaars, arXiv:2306.02161](https://ar5iv.labs.arxiv.org/html/2306.02161)). Production wake-word systems implement the temporal-evidence-accumulation half of this pattern with a simple, non-optimal but robust proxy for the theoretically-optimal Sequential Probability Ratio Test: **posterior smoothing plus a minimum-consecutive-frames-above-threshold rule**, with a concretely cited operating rule of "if P(keyword) > 0.8 for 3 consecutive frames, trigger" ([wake-word engineering synthesis](https://www.arunbaby.com/speech-tech/0040-wake-word-detection/)). SPRT's asymmetric-threshold design — independently controllable false-accept and false-reject bounds — is structurally better matched than a symmetric z-score or a fixed consecutive-hit window to a setting where false accepts must be suppressed far more aggressively than false rejects, though no source found gives a head-to-head empirical comparison of SPRT, Bayesian online changepoint detection, and a hard consecutive-hit counter on a genuinely visual absence/presence task — this remains an inference from each method's known properties, not a cited result.

## Open-gallery re-ID suppresses false matches with margins, calibration, and quarantined growth

Open-set person and animal re-identification reframes matching as verification (score-vs-threshold) rather than forced closed-set retrieval, evaluating Detection-and-Identification Rate against False Accept Rate rather than rank-1 accuracy, because most probes in a realistic deployment correspond to no gallery identity at all ([Open-set Person Re-ID](https://arxiv.org/abs/1408.0872)). The field has moved decisively toward **calibrated similarity with a margin-over-runner-up check** rather than raw distance or aggressive re-ranking: the WildFusion open-set animal re-ID pipeline applies isotonic calibration to each of three similarity branches, accepts a match only if the best similarity exceeds an absolute threshold τ_attach **and** its margin over the second-best identity exceeds τ_margin, and computes an identity-level score as the average of the top-r similarities (not the single best) so no one lucky or unlucky comparison dominates ([Calibrated Similarity and Graph Clustering, arXiv:2608.02469](https://arxiv.org/html/2608.02469)). This margin-plus-averaging pattern recurs independently across the cattle-muzzle benchmark's τ=2 confidence-ratio gate and the MICRO-TRACK industrial system's dual-threshold cascade (detection-confidence gate before re-ID is even attempted, then embedding-distance to class centroids), reaching Precision 0.908 at th_score≈0.91–0.92 on its Facility-ReID dataset ([Self-Adaptive Gallery Construction, Sensors 2023 / PMC10007633](https://pmc.ncbi.nlm.nih.gov/articles/PMC10007633/); [MICRO-TRACK, arXiv:2409.03879](https://arxiv.org/html/2409.03879v1)). Notably, closed-set re-ranking tricks (k-reciprocal encoding, average query expansion) built for boosting rank-1/mAP are explicitly flagged as unvalidated — and potentially harmful — for the open-set absent-target case, because they can propagate a false match by pulling in its neighbors; Bayesian Query Expansion, which only pools features estimated to be true matches, is the calibrated alternative ([Bayesian Query Expansion](https://vana77.github.io/images/prl_reid.pdf)). Recent benchmarks also puncture optimism about oracle-tuned thresholds: the 2026 Open-Set Cattle Muzzle benchmark shows that a threshold picked in-sample achieves 96–98% DIR at FAR=10⁻², but under realistic deployable calibration (threshold fixed only from a held-out validation-unknown split, never from test or training data) FAR roughly doubles to 1.0–2.4% — a warning that any threshold calibrated against the small pool of known reference images alone will systematically underestimate real-world false-accept rate ([Open-Set Cattle Muzzle, arXiv:2608.28663](https://arxiv.org/html/2608.28663)).

For online gallery updating — the direct analog of accumulating "recently confirmed detections" as extra anchors around a 2–3-image reference set — every safeguarded method found uses the same four-part pattern: gate admission with both an absolute confidence threshold *and* a margin-over-runner-up check; require corroboration or diversity gain rather than accepting any single high-scoring detection outright; aggregate/average across multiple stored references so no single bad addition dominates; and bound the reference pool (circular buffer or active pruning) so poisoned or stale entries eventually age out. Casao et al.'s Self-Adaptive Gallery Construction routes any sample failing its confidence-margin test not to immediate rejection but to a **quarantine ("Unknown Data Manager")** that is periodically re-clustered with DBSCAN and compared against existing gallery members before admission, plus a skeleton-visibility quality pre-filter before a sample is even eligible for clustering, and an entropy-diversity pruning rule to actively remove redundant or confusing gallery members rather than only ever growing the set ([PMC10007633](https://pmc.ncbi.nlm.nih.gov/articles/PMC10007633/)). MICRO-TRACK's Open-Set Gallery bounds the blast radius of any single bad embedding structurally, by keeping only a fixed-size circular buffer per identity rather than an ever-growing set, so a mistaken addition ages out automatically ([arXiv:2409.03879](https://arxiv.org/html/2409.03879v1)). WildFusion adds a further corroboration safeguard specific to clustering-based verification: a whole cluster of probe images is only assigned to a known identity if at least one member received a confident vote for that identity and it has the highest accumulated vote — meaning a single ambiguous or false match cannot unilaterally attach a group of detections to the wrong identity ([arXiv:2608.02469](https://arxiv.org/html/2608.02469)). No paper found describes an explicit *rollback* mechanism — detecting and retroactively removing a poisoned gallery entry once contradicting evidence later appears — every safeguard found is preventive (gating before admission) rather than corrective (curing an already-admitted error), which is a real, unaddressed gap for a long-running streaming deployment. Wildlife and livestock re-ID is, overall, the closest available analog to a genuinely 1–3-shot streaming deployment: it treats "probed individual is absent from the gallery" as the default assumption rather than an edge case, normalizes around one-to-few-shot enrollment (91% rank-1 from a single reference image in the cattle-muzzle benchmark), and combines global embedding similarity with local keypoint-matching branches for extra verification signal precisely because reference counts are low ([arXiv:2608.28663](https://arxiv.org/html/2608.28663); [arXiv:2608.02469](https://arxiv.org/html/2608.02469)).

## No paper fuses a global statistic with local structure — and that gap explains DAVE's shortfall

A targeted search for papers explicitly framing verification as "global aggregate statistic fused with local graph/cluster structure" found no such named architecture in detection, re-ID, or few-shot verification for 2023–2025. What exists instead are two adjacent but distinct literatures. The first is classical reject-option theory, which formally distinguishes a **global** threshold (constant across the whole input space) from a **local** threshold strategy (region-, cluster-, or prototype-conditioned), and reports that local reject options measurably help *simple, prototype-based* classifiers but merely reach parity with a well-calibrated global/SVM-style threshold once the underlying classifier is already sophisticated ([Fischer, Hammer & Wersing, arXiv:1503.06549](https://arxiv.org/html/1503.06549)). The same literature's best-practice combination pattern is **sequential cascade with early exit** — a cheap, ordered rejector runs first, and only surviving examples reach a more expensive, local structural check — echoing Giusti et al.'s classic two-stage design of a global classifier-with-rejection followed by a local nearest-neighbor classifier, plus an OR-gate rule when the two signals catch non-overlapping failure modes ([Hendrickx et al. survey, arXiv:2107.11277](https://ar5iv.labs.arxiv.org/html/2107.11277)). Critically, no source recommends naive weighted-averaging or voting between a global statistic and a local structural signal — the literature's uniform preference is strict sequential gating or explicit region-conditioning of thresholds, never blending into one score. The second adjacent literature is GNN-based MOT/ReID association (Brasó & Leal-Taixé's neural solver, TrackMPNN, GLCNet), where "global" reasoning is achieved architecturally — message passing over a graph spanning the *entire* set of detections — rather than statistically, via a separate population-level threshold; this is a materially different mechanism from computing an aggregate statistic across many frames and then checking local structure, and no GNN-ReID paper found computes a genuinely dataset-wide statistic (e.g., a running mean/variance of match scores across a whole video) as a distinct signal combined with graph-neighborhood consensus ([arXiv:1912.07515](https://arxiv.org/abs/1912.07515); [arXiv:2101.04206](https://arxiv.org/abs/2101.04206)).

A direct check of the DAVE paper and its citation graph confirms the project's own empirical finding is not addressed, or even acknowledged, in the published literature. DAVE's verification stage applies spectral clustering to an affinity matrix built **independently per image** — candidate-detection features and exemplar features drawn only from that single image, with no dataset-level, video-level, or cross-image aggregate statistic anywhere in the pipeline; the paper's own limitations section discusses dense-packing detection error, not per-image isolation ([DAVE, arXiv:2404.16622](https://arxiv.org/html/2404.16622)). None of DAVE's located citing papers (a "Detect Anything via Next Point Prediction" follow-up, a unified low-shot counting-by-detection-and-segmentation paper, CountGD, and a zero-shot counting paper) propose adding a global or aggregate signal to its verification stage or critique its per-image isolation — the weakness the project identified empirically is, as far as this search could establish, a genuine and unaddressed gap rather than a known-and-solved problem. This is directly consistent with why per-keyframe clustering verification underperformed a global adaptive threshold in this project's own pipeline: DAVE's counting setting (FSC147-style) guarantees real instances of the counted class in every image, so a per-image clustering decision always has at least one true cluster to anchor against; in a tracking deployment where **most keyframes contain zero true target instances**, that same per-image clustering procedure has no population-level context to lean on and must decide, from a handful of candidate detections in one frame alone, whether any of them are real — precisely the low-information, small-sample regime where reject-option theory predicts a purely local rule underperforms or at best matches a global one. A global adaptive threshold, by contrast, functions like reject-option theory's global rejector or the camera-trap/wake-word cascade's first stage: it is calibrated across the accumulated evidence of a majority-negative stream (implicitly incorporating the population-level base rate that "absent" is the default), which is exactly the information a single isolated frame's local clustering step cannot see.

## Conclusion

The literature does not offer a single off-the-shelf paper that solves "few-shot, target-mostly-absent, online precision verification," but it converges strongly enough across five independent sub-fields (VOT, conformal statistics, anomaly detection, open-set recognition, and ReID) to specify a concrete architecture: a global, recall-favoring, self-adjusting pre-filter (ACI/PID-style if an approximate correctness signal is available, or a simpler FAR-calibrated threshold against a background/negative pool otherwise) should gate which frames even reach a local structural verification step, and that local step — nearest-neighbor-to-3-exemplar distance with a margin-over-runner-up check, in the style of WildFusion and the cattle-muzzle benchmark — should only be trusted to update persistent state (template, gallery, threshold) when a reliability/corroboration gate is also satisfied, never on a single high score alone. The project's finding that per-keyframe DAVE-style clustering underperformed a global adaptive threshold is not an anomaly to be engineered around with a better clustering algorithm; it is the predictable consequence of running only the second (local) stage of a cascade whose first (global) stage was never built, in a domain where the base rate the first stage would encode — target absent in the overwhelming majority of frames — is exactly the information a per-image method structurally cannot access. The genuine open research gap this survey surfaced — no paper explicitly fuses a global aggregate statistic with a local graph/cluster structure as a named verification architecture, and no paper solves online conformal calibration under the joint conditions of severe imbalance and self-labeled feedback — is also the most promising place for this project's own engineering contribution: composing an imbalance-aware, corruption-compensated online threshold (F-ROCP/AC-ROCP-style) as the global gate, with margin-calibrated few-shot matching and corroboration-gated memory writes as the local verification and update stages, would be a genuinely novel synthesis rather than an application of an existing off-the-shelf method.
